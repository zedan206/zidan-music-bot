# 🎵 بوت الموسيقى لديسكورد

بوت ديسكورد مبني بـ Node.js لتشغيل الأغاني في القنوات الصوتية باستخدام مكتبة DisTube.

---

## ✨ المميزات

- ▶️ تشغيل أغاني من يوتيوب برابط أو باسم الأغنية
- 📋 قائمة تشغيل (Queue) متعددة الأغاني
- ⏭️ تخطي الأغاني
- ⏸️ إيقاف مؤقت واستئناف
- 🔂 وضع التكرار (أغنية واحدة / القائمة كاملة)
- 🔊 التحكم في مستوى الصوت
- 📊 عرض معلومات الأغنية الحالية
- 🎨 رسائل مدمجة (Embeds) جميلة

---

## 📋 الأوامر

| الأمر | الاختصار | الوصف |
|-------|----------|-------|
| `!play [رابط/اسم]` | `!p` | تشغيل أغنية أو إضافتها للقائمة |
| `!skip` | `!s` | تخطي الأغنية الحالية |
| `!stop` | `!st` | إيقاف التشغيل ومسح القائمة |
| `!queue` | `!q` | عرض قائمة الأغاني |
| `!pause` | - | إيقاف مؤقت |
| `!resume` | `!r` | استئناف التشغيل |
| `!volume [1-100]` | `!v` | ضبط مستوى الصوت |
| `!loop` | `!l` | تبديل وضع التكرار |
| `!nowplaying` | `!np` | معلومات الأغنية الحالية |
| `!help` | `!h` | عرض قائمة الأوامر |

## ⚙️ طريقة الإعداد

### 1. استنساخ المشروع
```bash
git clone https://github.com/username/discord-music-bot.git
cd discord-music-bot
```

### 2. تثبيت المكتبات
```bash
npm install
```

### 3. إعداد ملف البيئة
```bash
cp .env.example .env
```
ثم افتح ملف `.env` وضع توكن البوت:
```
DISCORD_TOKEN=توكنك_هنا
```

### 4. تشغيل البوت
```bash
npm start
```

---

## 🔑 الحصول على توكن البوت

1. اذهب إلى [Discord Developer Portal](https://discord.com/developers/applications)
2. أنشئ تطبيقاً جديداً
3. اذهب إلى قسم **Bot**
4. انسخ التوكن وضعه في ملف `.env`
5. فعّل **Message Content Intent** في إعدادات البوت
